Sources and context

Data and credits

The screens on this website illustrate the AcreOutlook app. Field names, crop stages and forecast readings in the examples are demo data, not current advice or a real customer’s records. Map imagery may reflect the captured map view rather than the illustrative forecast.

Weather sources

The app uses NOAA / National Weather Service weather and radar products and Open-Meteo weather data. Open-Meteo data is available under CC BY 4.0. AcreOutlook converts units, summarizes forecasts and derives planning estimates. Commercial service access is governed separately by provider terms. No provider endorsement is implied.

NWS material is public domain unless otherwise noted. AcreOutlook’s derived estimates are not official government advisories. See the NWS usage notice.

Maps

Captured map views use Mapbox software, map styles and data, with underlying OpenStreetMap contributions. Mapbox branding remains visible in the example map. Map credits: © Mapbox, © OpenStreetMap, Improve this map. The static marketing site does not make live map or weather API requests.

Interface and artwork

The temporary wheat mark uses paths from Lucide, under the ISC license with Feather contributions acknowledged. Read the icon license.

Manrope is used under the SIL Open Font License 1.1. Read the font license. The dimensional sun and cloud artwork was AI-generated for this project. The final AcreOutlook logo is still in development.

Planning context

Crop development benchmarks, water outlooks and work windows support field checks. They do not diagnose disease, guarantee yield, prescribe irrigation or approve chemical applications. Observations and estimates remain distinct in the app. Custom commodity labels do not automatically establish a crop-specific model.
